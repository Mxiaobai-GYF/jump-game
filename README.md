# 像素跳跃 · 云端版 🎮

> 按住鼠标蓄力，滑动改变抛物线方向，松开跳跃！
> 踩平台得分，吃星星加分，和好友比比谁跳得更高。

---

## 怎么玩

| 操作 | 效果 |
|------|------|
| 按住鼠标左键 | 蓄力（条越长跳越高） |
| 按住鼠标左右拖动 | 改变跳跃方向（往左拖往右跳） |
| 松开鼠标 | 跳出去！ |
| 踩中新平台 | +1 分 |
| 吃到星星 | +5 分 |
| 掉出屏幕 | 游戏结束 |

---

## 开始游戏

**1.** 启动后端

```
uvicorn main:app --reload --port 8000
```

**2.** 打开 `index.html` → 注册 / 登录 → 自动进入游戏

或者直接打开 `game.html?player_id=xxx`
